# Dharma Clinic: обновления

Это служебный открытый репозиторий: здесь лежит только список обновлений и готовые пакеты расширения «Dharma Clinic» для Joomla. Исходный код ведётся отдельно.

Joomla проверяет файл `updates/pkg_dharmaclinic.xml` и показывает новую версию в **Система → Обновление → Расширения**. Адрес файла записан в манифесте пакета (`<updateservers>`), так что на сайтах он появляется сам при установке пакета, где он указан.

Пакеты: [Releases](../../releases).
